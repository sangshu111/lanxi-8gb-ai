# AI 文生视频实战教程（即梦 / 可灵 / 海螺 / RunningHub）

> 适用：想把一张图或一句话变成 5~10 秒短视频。
> 结论先说：**提示词不是「描述画面」，是「给导演的分镜单」。**

## 二、提示词公式（记这一条就够）

```
【主体】+【动作】+【场景】+【镜头】+【光线】+【风格】+【参数】
```

**示例（差 → 好）**

```
❌ 生成一个女孩在便利店
✅ 蓝发女仆装少女坐在购物车里回头看向镜头，身后两名同伴推着车；
   夜景便利店门口，荧光灯冷白主光 + 店内暖黄逆光；
   广角低角度跟拍，浅景深；日系动画赛璐璐风格，干净细线；
   横屏 16:9，5 秒
```

**为什么第二个好**：它给了**镜头怎么动**、**光从哪来**、**景深多少**——这三个是视频和图片最大的差别。

## 三、七个必须写清楚的要素

### 1. 主体（谁）
人物写**外貌锚点**：发色、发型、服装、标志物。

```
蓝发、双麻花辫、猫耳耳机、红色连帽衫
```

### 2. 动作（在干什么）—— 一条视频只写一个动作
```
✅ 回头看镜头、慢慢抬手、推着购物车走
❌ 一边走一边回头一边挥手（模型会糊）
```

### 3. 场景（在哪）
```
便利店门口、停车场、路灯下、雨夜霓虹街道
```

### 4. 镜头（怎么拍）—— 最容易漏，也最影响观感

| 写法 | 含义 |
|---|---|
| `固定镜头` | 机位不动，最稳 |
| `缓慢推近` | 情绪递进 |
| `环绕拍摄` | 展示角色 |
| `低角度仰拍` | 压迫/英雄感 |
| `广角鱼眼` | 夸张透视 |
| `浅景深` | 背景虚化，突出主体 |
| `跟拍` | 跟着人物一起动 |

### 5. 光线（什么光）
```
荧光灯冷白 / 夕阳侧逆光 / 霓虹冷暖对撞 / 室内暖黄台灯
```

### 6. 风格（像什么）
```
日系动画赛璐璐 / 写实电影感 / 吉卜力 / 复古胶片
```

### 7. 参数（多长多宽）
```
5 秒 / 10 秒，16:9 或 9:16，1080P
```

## 四、四种高级玩法

### 4.1 图生视频（最推荐）
**先生图，再让它动**。因为：
```
· 人物长相锁死在图里，视频不会跑脸
· 构图、光线、服装全都定了
· 只要写「怎么动」，提示词短一半
```

写法：**只写动作 + 镜头**，别再描述外观。

```
✅ 她慢慢抬头看向镜头，头发被风吹动，镜头轻微前推，5 秒
```

### 4.2 首尾帧（关键帧控制）
给两张图（起始 / 结束），模型补中间过程。

```
适合：转身、站起、拿起杯子、门打开
不适合：两个完全无关的场景（会硬切）
```

### 4.3 动作迁移（让角色照视频动作动）
RunningHub 上有 Wan2.2 Animate 这类工作流：**给一张角色图 + 一段真人动作视频**，输出角色做同样动作。

**这是目前做「角色固定 + 动作真实」最省事的办法。**

### 4.4 分段拼接
一条 10 秒做不好，就做两条 5 秒，再拼。

```
镜头1：拉远景交代环境（5s）
镜头2：中景推进（5s）
剪辑时中间加一个 0.3 秒的遮挡或白闪，衔接自然
```

## 五、六个常见问题与解法

| 问题 | 原因 | 解法 |
|---|---|---|
| 人物脸崩 / 变形 | 纯文生视频没有锚点 | 改**图生视频**，或用参考图 |
| 手部畸形 | 视频模型通病 | 手别放画面正中心，或用近景避开 |
| 画面闪烁、抖动 | 动作幅度太大 | 动作写小一点，镜头写「固定」 |
| 动作做一半就结束 | 时长短 | 5 秒只写一个动作 |
| 后半段画风突变 | 提示词太杂 | 一条视频只保留一个风格词 |
| 人物数量对不上 | 多人容易糊 | 主体只写 1 人，其他写「背景里有人影」 |

## 七、我们自己的用法（可复用）

短剧系列的设计已经写成表格，直接抄：

```
docs/30-拇指大的她-豆包视频提示词与剧本.md     剧本 + 分镜
docs/31-拇指大的她-10秒单镜头提示词.md         每个镜头一条完整提示词
docs/32-拇指大的她-整条时间轴总表.md           6×10 秒，带时间码
```

**流程**：

```
1. 写剧本（谁、在哪、发生什么）
2. 拆成 6 个 10 秒镜头
3. 每个镜头出一张定妆图（用 SDXL / NovelAI）
4. 图生视频，只写动作和镜头
5. ffmpeg 拼接 + 配音 + BGM
```

## 八、一句话总结

> **文字描述画面，图片锁定长相，提示词只负责「怎么动、怎么拍」。**

先跑图，再做视频，成功率会高一个数量级。
