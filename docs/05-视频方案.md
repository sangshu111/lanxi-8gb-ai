# 视频方案：让大肥鱼自己出镜讲解

> 目标：Q 版蓝色大肥鱼形象 + 拟真人设 + 自己的声线，做技术讲解视频。
> **不卖惨**，靠干货和性格。

---

## 一、形象方案选型

| 方案 | 效果 | 制作时间 | 8GB 显存 | 后续维护 |
|---|---|---|---|---|
| **A. 静态立绘 + 口型帧** | ⭐⭐ 能看 | **1 小时** | ✅ 不用显卡 | 换台词要重配 |
| **B. SadTalker / 口型驱动** | ⭐ 嘴型僵硬 | 2 小时 | ⚠️ 4GB | 每次生成慢 |
| **C. Live2D 绑定** | ⭐⭐⭐⭐ 最像 VTuber | 2~3 天（要绑骨） | ✅ 不用显卡 | 一次做好，长期用 |
| **D. 3D VRM + VSeeFace** | ⭐⭐⭐ 可动可转 | 1 天 | ⚠️ 建模吃显存 | 需 3D 建模 |

### 推荐路线

```
第一步（今天就能出片）：A 静态立绘 + 口型帧 + 剪映
第二步（有作品后）：C Live2D，做成能实时直播的形象
```

**理由**：

- A 的成本几乎为零，**1 小时能出第一条视频**
- 观众不会因为"嘴型不太准"而不看，**内容和性格才是关键**
- Live2D 绑定很花时间，等确定要做长线再投入

## 二、A 方案怎么做（静态立绘 + 口型）

### 1. 立绘（本地出图，25 秒）

```text
Q版, chibi, 2头身, 蓝色大肥鱼, 深蓝长发青蓝发梢, 呆毛, 鲸鱼鳍耳,
白色女仆头饰, 蓝白眼罩, 圆润脸型, 大眼睛, 张嘴笑,
简单白色背景, 正面, 上半身, 干净漫画风, cel shading
```

**需要出 3~5 张**：

| 用途 | 表情 |
|---|---|
| 主镜头 | 微笑 |
| 说话中 | 张嘴（口型 A） |
| 停顿/思考 | 闭嘴 |
| 吐槽/傲娇 | 挑眉、撇嘴 |
| 惊讶 | 张嘴大眼 |

**关键**：同一张脸，只换表情，**用固定 seed + 微调提示词**，保证一致性。

### 2. 口型帧（3 帧就够）

```
闭嘴（闭）→ 半开（中）→ 张开（大）
```

按音频的音量包络切帧：

```python
# 简单版：按 RMS 阈值分三档
rms = librosa.feature.rms(y=audio, frame_length=1024)[0]
for each_frame:
    if rms < 0.05:  mouth = "close"
    elif rms < 0.15: mouth = "half"
    else:           mouth = "open"
```

**帧率 12~15 fps 就够**（观众看不出来）。

### 3. 合成（剪映专业版）

```
轨道1：立绘/口型帧（按时间轴切）
轨道2：配音（GPT-SoVITS 生成）
轨道3：字幕（剪映自动识别，手动校对）
轨道4：演示素材（屏幕录制 / 出图过程）
```

**剪映的三个杀手功能**：

- **自动字幕**（识别配音，准确率 90%+）
- **文本朗读**（备用，但我们有自己的声线）
- **一键抠像**（立绘背景是白的，直接抠掉）

## 四、人设与讲稿风格

### 核心设定（基于已有人格）

| 维度 | 设定 |
|---|---|
| 身份 | 大肥鱼，蓝发鲸鱼女仆 |
| 性格 | 傲娇、有点懒、爱吐槽、偶尔傲娇翻车 |

| **禁忌** | ❌ 卖惨 ❌ 哭穷 ❌ 求三连（观众反感） |

### 稿子结构（每条视频）

```
【0-15秒】钩子：直接给结果 + 一句吐槽
   "8GB 显卡能跑 AI 老婆？我试了，还真行——顺便踩了 26 个坑。"

【15-60秒】结果展示
   "先看东西：出图 25 秒，说话 1.5 秒，全程没花一分钱 API。"

【1-6分钟】干货
   三个子系统，每个讲一个核心技巧

【6-8分钟】踩坑
   挑 3 个最痛的

【8-10分钟】收尾
   "仓库在这，代码全开源。有问题评论区骂我。"
```

## 五、剪辑软件选择

| 软件 | 优点 | 缺点 | 建议 |
|---|---|---|---|
| **剪映专业版** | 免费、自动字幕、上手快 | 复杂动效弱 | ✅ **首选** |
| Premiere Pro | 专业、插件多 | 收费、学习曲线陡 | 不必要 |
| After Effects | 动效强 | 只为动效学它太重 | 不必要 |
| DaVinci Resolve | 免费、专业调色 | 对硬件要求高 | 备选 |

**结论：剪映就够了**。AE 只在你需要复杂动效（比如架构图动画）时才用。

## 六、手机操控方案（备用）

如果一定要用手机版剪映：

```
① 手机开「USB 调试」
② 电脑装 scrcpy（开源投屏，延迟 <100ms）
③ 我用 ADB 发送点击/滑动坐标
```

**问题**：

- 剪映手机版界面元素位置会变，**坐标脚本很脆弱**
- 打字（字幕校对）几乎没法自动化

**建议**：**能用电脑版就用电脑版**，手机只用于拍摄/素材传输。
