# 语音：GPT-SoVITS v2Pro 零样本 + 后期链（8GB 实测）

> 目标：用自己截的声音切片，让角色说话，1.5 秒/句，音色接近原声。

---

## 一、效果演进（我们踩过的 5 个坑）

| 版本 | 现象 | 原因 | 解决 |
|---|---|---|---|
| v1 | **沙哑 + 大舌头** | 没给参考音频的文字（`ref_free=True`），模型瞎猜 | 用 Whisper 转写出 `prompt_text` |
| v2 | 咬字黏连 | 用的是 v2 老模型 | 换 **v2Pro** |
| v3 | **说话变快 1.5 倍** | 变调用重采样，同时缩短了时长 | 改 `librosa.effects.pitch_shift`（保时长） |
| v4 | **有气无力**（RMS −24dB） | 只做了峰值归一，没做压缩 | 加动态压缩 + RMS 归一到 −16dBFS |
| **v5** | 定稿 | — | 1.5 秒/句，响度稳定 |

## 二、参考音频怎么挑（最关键）

**不是随便挑一条就能用**。要按指标筛：

| 指标 | 怎么算 | 目标 | 为什么 |
|---|---|---|---|
| **谱平坦度** | `librosa.feature.spectral_flatness()` | **< 0.03** | 越高越像噪声/气声 → 磨砂感 |
| **中位音高** | `pyin` 取中位数 | 少女 285~345Hz；成熟女声 170~240Hz | 决定"年龄感" |
| **音高标准差** | 半音标准差 | 越大越好（>3） | 起伏大 = 活泼，小 = 念稿 |
| **句尾斜率** | 最后 25% 帧的线性拟合 | **> −0.05** | 负太多 = 每个字都往下沉（"丧"） |

### 实测：423 条里只有 2~3 条能过严筛

```python
def analyze(path):
    y, sr = librosa.load(path, sr=16000)
    flat = np.mean(librosa.feature.spectral_flatness(y=y))
    if flat > 0.03: return None          # 太脏，淘汰
    f0, _, _ = librosa.pyin(y, fmin=80, fmax=700, sr=sr)
    f0 = f0[~np.isnan(f0)]
    med = np.median(f0)
    std = np.std(12 * np.log2(f0 / 100))
    tail = f0[int(len(f0)*0.75):]
    slope = np.polyfit(np.arange(len(tail)), 12*np.log2(tail/100), 1)[0]
    return dict(med=med, std=std, slope=slope, flat=flat)
```

### 参考文本必须转写

```python
from faster_whisper import WhisperModel
asr = WhisperModel("small", device="cuda", compute_type="float16")
segs, _ = asr.transcribe(ref_wav, language="zh", beam_size=5)
prompt_text = "".join(s.text for s in segs).strip()
```

**这一步不做，音质直接掉一个档次。**

## 三、合成参数（定稿）

```python
cfg.version = "v2Pro"          # 比 v2 清楚很多
req = {
    "text": text, "text_lang": "zh",
    "ref_audio_path": ref,
    "prompt_text": ref_text,    # 必须是这条音频的真实文字
    "prompt_lang": "zh",
    "top_k": 16, "top_p": 1.0, "temperature": 1.0,
    "text_split_method": "cut0",  # 整句合成（cut5 会让句尾逐段下沉）
    "speed_factor": 0.97,
    "ref_free": False,            # 必须 False
    "repetition_penalty": 1.3,
}
```

**`cut0` vs `cut5` 的差别很大**：

- `cut5`：按短语切，每段独立合成 → **句尾必然降调**，听起来"每个字都在下沉"
- `cut0`：整句合成 → 语调自然

## 四、后期链（解决"有气无力"和"磨砂感"）

```python
y = denoise(y, sr)        # 1. STFT 谱减降噪
y = compress(y, sr)       # 2. 动态压缩
y = pitch_shift(y, sr, n) # 3. 变调（保时长！）
y = polish(y, sr)         # 4. EQ + 响度归一 + 软限幅
```

### 1. 谱减降噪

```python
S = librosa.stft(y, n_fft=1024, hop_length=256)
mag, phase = np.abs(S), np.angle(S)
noise = np.percentile(mag, 12, axis=1, keepdims=True)   # 取最低 12% 当噪声底
mask = np.clip((mag - 0.7*noise) / np.maximum(mag, 1e-8), 0.0, 1.0)
mask = uniform_filter(mask, size=(3,3))                 # 平滑，避免金属味
y = librosa.istft(mag*mask*np.exp(1j*phase), hop_length=256, length=len(y))
```

### 2. 动态压缩（解决"有气无力"）

```python
thresh_db=-20.0, ratio=3.0, attack=4ms, release=120ms, makeup=+5dB
```

**只做峰值归一是不够的**——峰值到 0.9 但 RMS 只有 −24dB，听起来就是"虚"。

### 3. 变调（必须保时长）

```python
# ❌ 错误：重采样变调，时长会缩短 25~33%
y = np.interp(np.arange(0, len(y), 2**(st/12)), np.arange(len(y)), y)

# ✅ 正确：相位声码器，时长不变
y = librosa.effects.pitch_shift(y, sr=sr, n_steps=st)
```

### 4. 响度归一 + 软限幅

```python
y = y * (10**(-16/20) / rms)          # 归一到 -16 dBFS
y = np.tanh(y * 1.15) / np.tanh(1.15) # 软限幅，别用硬削波
y *= 0.95 / np.abs(y).max()
```

**硬削波会把响度压回去**——这是 v4 "有气无力"的真正原因。

## 五、按需服务（不占显存）

模型加载要 **9 秒 + 1.5GB 显存**，所以做成"用的时候启动，空闲自动退出"。

```python
# voice-service.py
服务启动 → 预热模型 → 监听 127.0.0.1:9880
收到 /say → 合成 → 返回 wav 路径
空闲 300 秒 → 自动退出，显存归零
```

**实测**：

| 状态 | 显存 | 响应 |
|---|---|---|
| 运行中 | 1.6 GB | **1.5 秒/句** |
| 空闲退出后 | **0** | 冷启动 34 秒 |

**客户端**（`voice-client.mjs`）会自己检查服务在不在，不在就拉起来。

```bash
node scripts/voice-client.mjs --voice shenhe --text "主人，你回来啦。"
```

## 六、环境安装（Windows 踩坑合集）

| 问题 | 解决 |
|---|---|
| `transformers` 太新，AutoTokenizer 选错类 | 钉死 `4.44.2` + `tokenizers 0.19.1` |
| `jieba_fast` 没有 Windows 轮子 | 写兼容层转发到 `jieba` |

| `pretrained_models/fast_langdetect` 目录不存在 | 手动 `mkdir` |

## 八、其他语音引擎对比

| 引擎 | 优势 | 微调难度 | 备注 |
|---|---|---|---|
| **GPT-SoVITS** | 中文最强、资料多 | 中 | 本项目使用 |
| CosyVoice2 | 零样本开箱即用 | 低 | 值得对比 |
| IndexTTS2 | 情绪控制好 | 中 | — |
| Fish-Speech | 多语言 | 中 | — |
| F5-TTS | 快、轻 | 低 | — |

**换引擎不会自动变真实**——音质取决于三件事：参考音频质量、是否微调、后期处理。
