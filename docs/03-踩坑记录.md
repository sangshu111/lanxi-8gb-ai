## 一、环境 / 依赖

### 1. torch 装不上：SSL EOF

**症状**

```
SSLError(SSLEOFError(8, '[SSL: UNEXPECTED_EOF_WHILE_READING]'))
ERROR: Could not find a version that satisfies the requirement torch
```

**原因**：`download.pytorch.org` 走代理时会 TLS 中断。

**解决**：用镜像直接下 whl

```
https://mirrors.aliyun.com/pytorch-wheels/cu128/
```

### 2. RTX 50 系显卡跑不了

**症状**：`torch.cuda.is_available()` 返回 False，或报 `no kernel image is available`

**原因**：RTX 50 系是 Blackwell（sm_120），**必须 CUDA 12.8 以上**的编译版本。

**解决**

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
# 验证
python -c "import torch;print(torch.cuda.get_device_capability(0))"   # 应该是 (12, 0)
```

### 3. 装了某个包之后 torch 被降级

**症状**：`torchvision::nms does not exist`

**原因**：`controlnet_aux` 之类的包会把 torch 拖回旧版/CPU 版。

**解决**：装完后**重装**匹配的 torch + torchvision

```bash
pip install --force-reinstall --no-deps torch-2.7.1+cu128-*.whl
pip install --force-reinstall --no-deps torchvision-0.22.1+cu128-*.whl
```

### 4. transformers 版本地狱

| 组合 | 结果 |
|---|---|
| transformers 5.x + torch 2.3 | ❌ 要求 torch≥2.6 |
| transformers 4.44 + hub 1.32 | ❌ hub 太新 |
| hub 0.24.7 + diffusers 0.40 | ❌ diffusers 要 hub≥1.23 |
| **transformers 4.44.2 + hub 0.24.7 + diffusers 0.31** | ✅ |

### 5. `jieba_fast` 编译失败

**症状**：`Failed to build installable wheels for jieba_fast`

**原因**：没有 Windows 预编译轮子，需要 C 编译器。

**解决**：在 `site-packages` 里放一个转发层

```python
# jieba_fast.py
import jieba as _jieba, jieba.posseg as _posseg
import sys
sys.modules[__name__ + ".posseg"] = _posseg
lcut = _jieba.lcut
def __getattr__(name): return getattr(_jieba, name)
```

## 二、出图

### 6. 出图 320 秒（正常应该 25 秒）

**原因**：显存 10.5GB > 8GB，溢出到共享内存。

**解决**

```python
pipe.enable_model_cpu_offload()
pipe.enable_vae_slicing()
pipe.enable_vae_tiling()
```

### 7. 图片变扁

**原因**：裁切比例和输出比例不一致，硬拉伸。

**解决**：**永远按目标比例裁切**

```python
crop_w = int(h * (832/1216))       # 反推裁切宽度
crop.resize((832, 1216))            # 同比例缩放，不会变形
```

或用**白边补齐**

### 8. 三视图切不开

**症状**：裁出来总带邻图的边。

**试过但不行的**：

- ❌ 硬切 1/3 宽 → 邻图残边
- ❌ 阈值找空白列 → 背景是灰白渐变，阈值失效
- ❌ 背景色差分割 → 三个人物**挨着的**，中间没有空白列

**有效**：**列覆盖率的局部极小值**

```python
smooth = np.convolve(mask.mean(axis=0), np.ones(21)/21, mode="same")
s1 = argmin(smooth[0.26w : 0.42w])
s2 = argmin(smooth[0.58w : 0.74w])
```

### 9. 尾巴变成一整条鲸鱼

**原因**：训练集里「尾鳍」和「鲸鱼玩具」混在一起，LoRA 学混了。

**缓解**（治标）

```text
负向：whole whale, whale plush, stuffed animal
```

**根治**（治本）：重训，两种形态分开打标。

### 10. 提示词写了但没生效

**症状**：明明写了 `white stockings`，出来是光腿。

**原因**：**CLIP 只认 77 token，超了从后面截断**。

**排查**：看日志有没有

```
Token indices sequence length is longer than the specified maximum sequence length (98 > 77)
```

**解决**：精简到 70 token 以内，**关键项放前面**。

### 11. 画风油润 / 塑料感

**解决**

```
正向：clean manga style, cel shading, flat colors, crisp lineart, matte, dry color
负向：glossy, shiny skin, oily, wet look, bloom, airbrushed, 3d, painterly, plastic, doll-like
```

### 12. 画风突然变素描

**原因**：加了 `anime screentone` 之类的词，模型理解成"漫画分镜/草稿"。

**解决**：负向补 `sketch, rough sketch, unfinished, monochrome, pencil`。

### 13. ControlNet 不生效，姿势还是站姿

**原因**：LoRA 权重太高（0.72），模型更听 LoRA 的。

**解决**：LoRA 降到 **0.66**，ControlNet 拉到 **0.95~1.0**。

### 14. ControlNet 生效了但角色颜色变了

**原因**：LoRA 权重太低（0.45），角色特征丢失（头发变亮蓝、眼睛发红）。

**解决**：这就是 13 和 14 的**夹缝**，0.6~0.7 之间找平衡。

### 15. 自动提取的骨架是错的

**症状**：明明输入跪姿图，骨架出来是站姿。

**原因**：长裙遮住腿，OpenPose 检测不到关键点。

**解决**：**自己画骨架**（见 `scripts/pose-skeleton.py`），按 COCO 18 点硬编码坐标。

## 三、语音

### 16. 声音沙哑 + 大舌头

**原因**：`ref_free=True`（没给参考音频的文字）。

**解决**：Whisper 转写 → 填 `prompt_text` → `ref_free=False`。

### 17. 每个字尾音都往下沉

**原因**：`text_split_method="cut5"`，按短语切分，每段独立合成，段尾必然降调。

**解决**：`cut0`（整句合成）。

### 18. 说话快 1.5 倍

**原因**：变调用了重采样，音高上去的同时时长缩短了。

**解决**

```python
# ❌ y = np.interp(np.arange(0,len(y),f), ...)
# ✅
y = librosa.effects.pitch_shift(y, sr=sr, n_steps=st)
```

### 19. 有气无力

**原因**：只做峰值归一，RMS 只有 −24dB。

**解决**：动态压缩 + RMS 归一到 −16dBFS。注意**软限幅**，硬削波会把响度压回去。

### 20. 参考音频选错，怎么调都不像

**原因**：用了处理过的音频（降噪/重采样过的），等于"从压缩图再临摹"。

**解决**：**只用原始切片**，并按四个指标筛（谱平坦度 / 中位音高 / 音高标准差 / 句尾斜率）。

### 21. GPT-SoVITS 训练卡在语义提取

**症状**：`6-name2semantic-0.tsv` 输出 0 字节。

**已确认**：

- `i_part` / `all_parts` 必须设环境变量（否则 `TypeError: int() argument must be... NoneType`）
- `s2_train.py` 需要 `s2.json` 里有 `gpu_numbers` 和 `exp_dir`
- `s1_train.py` 的 yaml 需要 `if_save_latest` / `if_dpo` / `half_weights_save_dir`

**状态**：仍未跑通，见 docs/02-语音.md 第七节。

## 四、系统 / 磁盘

### 22. 系统盘满了（30G）

**症状**

```
No space left on device
/tmp 不可用 → FileNotFoundError: No usable temporary directory
```

**解决**

```bash
pip cache purge                    # 清缓存（我们清了 6GB）
rm -rf ~/.cache
export TMPDIR=/root/autodl-tmp     # 临时目录挪到数据盘
```

### 23. 云端 git clone 卡死

**解决**

```bash
curl -L -o repo.zip https://ghproxy.net/https://github.com/用户/仓库/archive/refs/heads/main.zip
```

### 24. 一个配置文件下载了 14 次，JSON 解析失败

**症状**：`json.decoder.JSONDecodeError: Extra data: line 57 column 1`

**原因**：断点续传脚本在文件已存在时又追加写了一遍，14 个 JSON 对象拼在一起。

**解决**：小文件（<1MB）**别用续传**，直接覆盖写。

## 五、运维

### 25. 自动点击网页按钮无效

**症状**：`element.click()` 没反应。

**原因**：Vue 编译后的事件绑定，合成事件被丢弃。

**有效**：`Input.dispatchMouseEvent`（真实鼠标事件），或对 Element Plus 的 `.click()`（它是真 `<button>`）。

**无效**：`new MouseEvent()`、`new PointerEvent()`。

### 26. SSH 密码自动填充（Windows）

**解决**

```powershell
# 造一个 askpass 脚本
Set-Content askpass.cmd "@echo off`necho $password"
$env:SSH_ASKPASS = 'E:\...\askpass.cmd'
$env:SSH_ASKPASS_REQUIRE = 'force'
$env:DISPLAY = 'localhost:0'
ssh -p 22 root@host "命令"
```

## 六、经验总结

1. **先验证再优化**——别急着下 3GB 模型，先用 10 秒的测试确认流程通
2. **看日志不要猜**——`tail -30` 比"我觉得应该是"快 10 倍
3. **小文件别续传**——会追加写坏
4. **显存不够就 offload**——慢总比跑不动好
5. **提示词有长度上限**——77 token，写了不生效先查这个
6. **数据比参数重要**——尾巴问题在数据，不在提示词
