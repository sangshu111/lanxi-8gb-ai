# 发布指南：GitHub + 视频选题

> 你电脑上**没有装 git**，所以下面给「网页上传」和「装 git」两种方式。

---

## 一、发到 GitHub（网页版，5 分钟）

### 1. 建仓库

1. 打开 https://github.com/new
2. Repository name：`lanxi-8gb-ai`
3. Description：`8GB 显存笔记本上搭 AI 角色：出图 + 语音 + 人格`
4. 选 **Public**（公开才能被搜到）
5. **不要**勾选 "Add a README file"（我们已有）
6. Create repository

### 2. 上传文件

新仓库页面会显示 "uploading an existing file" 链接：

```
点击 → 把项目文件夹里的所有文件拖进去
→ Commit changes
```

**注意**：网页上传**支持拖整个文件夹**（会保留目录结构），但单次限制 **100 个文件 / 25MB**。

我们只有 14 个文件，没问题。

### 3. 加个封面图（可选但重要）

```
assets/cover.png   ← 放一张最好看的角色图
```

然后在 README 第一行加：

```markdown
![封面](assets/cover.png)
```

## 二、装 git（一次搞定，后面方便）

```powershell
# 用 winget
winget install --id Git.Git -e --source winget

# 装完验证
git --version
```

然后：

```powershell
cd <你的项目目录>
git init
git add .
git commit -m "init: 蓝汐 AI 角色管线"
git branch -M main
git remote add origin https://github.com/你的用户名/lanxi-8gb-ai.git
git push -u origin main
```

## 三、README 优化清单（提高星标率）

| 项 | 建议 |
|---|---|
| ✅ 开头一句话说清"解决什么问题" | 「8GB 显存跑出会说话会画画的 AI 角色」 |
| ✅ 放效果图（**最重要**） | 3~4 张对比图，不要文字堆砌 |
| ✅ 有实测数据表 | 「25 秒/张」「1.5 秒/句」比形容词有说服力 |
| ✅ 写清楚限制 | 诚实反而加分 |
| ❌ 不要贴大段代码 | 放 docs/ 里，README 只放关键命令 |

## 四、视频选题（B站）

### 选题 A：《8GB 显卡跑出会说话会画画的 AI 老婆》

**结构（8~12 分钟）**

| 段落 | 内容 | 时长 |
|---|---|---|
| 0. 钩子 | 直接放「她说话 + 出图」的成品画面 | 30 秒 |
| 1. 结果展示 | 3~4 张图 + 3 段语音 | 1 分钟 |
| 2. 硬件门槛 | 8GB 显存就够，成本 < ¥10 | 1 分钟 |
| 3. 三个子系统 | 出图 / 语音 / 人格（画个架构图） | 3 分钟 |
| 4. 最难的坑 | 挑 3 个最痛的（77 token、显存溢出、变调加速） | 3 分钟 |
| 5. 开源仓库 | 引导去 GitHub | 30 秒 |

**标题备选**

- `8GB 显存养 AI 老婆：出图 25 秒、说话 1.5 秒，全程免费`
- `我在笔记本上做出了会说话会画画的二次元角色`
- `不花一分钱 API：本地 AI 角色完整搭建`

### 选题 B：《我踩了 26 个坑，只为让 AI 不画错尾巴》

偏技术吐槽向，适合已有一定粉丝的账号。

### 选题 C：《AI 出图为什么会画出整条鲸鱼？——LoRA 数据集的坑》

单点深挖，适合技术区。

## 五、流量注意

| 点 | 说明 |
|---|---|
| **封面** | 一定要放角色图，不要放代码截图 |
| **前 10 秒** | 直接给结果，不要自我介绍 |
| **标题** | 带数字（8GB / 25 秒 / ¥10）点击率更高 |
| **多平台** | B站 + 抖音 + 小红书，同一套素材三处发 |
| **GitHub 引流** | 视频简介第一条放仓库链接 |
| **避坑** | 别碰「AI 替代画师」这种引战话题 |

## 六、关于"激励计划"

**GitHub 本身没有流量分成**。可能的收益路径：

| 平台 | 方式 |
|---|---|
| **B站** | 创作激励（需 1000 粉 + 播放量） |
| **掘金 / 思否** | 技术文章，部分有稿费 |
| **公众号** | 流量主（需 500 粉） |
| **GitHub Sponsors** | 需要海外账户 |
| **知识星球 / 小报童** | 付费专栏（这个最实际） |

**现实建议**：

```
① 先发 GitHub + B站，攒作品
② 有 50~100 星之后再考虑付费内容
③ 你真正的变现不是"这系列教程"，而是"能给别人定制角色"
```
