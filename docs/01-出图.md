# 出图：SDXL 角色 LoRA + ControlNet（8GB 显存实测）

> 目标：在 8GB 显存上，稳定画出「指定角色 + 指定姿势 + 干净漫画风」。

---

## 一、整体流程

```
① 准备数据集（参考图裁切）
   ↓
② 训练 LoRA（云端 3080Ti，约 30 分钟，¥1~2）
   ↓
③ 本地出图（SDXL + LoRA）
   ↓
④ 需要特定姿势 → ControlNet
   ↓
⑤ 出图后处理（可选）
```

## 二、数据集准备

### 原则

| 原则 | 说明 |
|---|---|
| **只用原始参考图** | 不要混入 AI 生成的图（会二次失真） |
| **裁切要等比** | 832:1216 = 0.684，裁完再缩放，**绝不拉伸** |
| **自动切片** | 三视图并排时，用列覆盖率局部极小值找分割线 |
| **数量** | 20 张起步，40~60 张效果明显更好 |

### 三视图自动切片

参考图常常是「正面 / 侧面 / 背面」并排，中间没有空白列，所以**不能**用「找空白列」的办法。

正确做法：**找列覆盖率的局部极小值**。

```python
# 背景色 = 四角平均
bg = corners.mean(axis=0)
mask = np.linalg.norm(arr - bg, axis=2) > 28
col_cov = mask.mean(axis=0)

# 在 [0.26w, 0.42w] 和 [0.58w, 0.74w] 区间找最小值，作为分割线
s1 = argmin(smooth[0.26w : 0.42w])
s2 = argmin(smooth[0.58w : 0.74w])
```

### 打标（caption）

```text
lanxi, 1girl, solo, mature female, long blue hair, gradient blue to cyan tips, ahoge,
blue eyes, white lace maid headdress with blue bows, small soft whale fin ears,
blue and white victorian maid dress, white apron with blue whale motif,
white over-knee stockings, blue mary jane shoes, white background
```

**注意**：

- **不同形态要分开打标**（这条踩坑最深）
  - `whale tail fin`（尾鳍，从裙后伸出）
  - `whale plush`（整条鲸鱼玩具）
  - 混在一起 → 模型会画出一条鲸鱼缠在身上
- **不要写姿势词**（正面/侧面让模型自己学）

## 四、本地出图（8GB 关键优化）

### 必须做的三件事

```python
pipe = StableDiffusionXLPipeline.from_single_file(CKPT, torch_dtype=torch.float16)

pipe.enable_model_cpu_offload()   # 或 enable_sequential_cpu_offload()（带 CN 时必须）
pipe.enable_vae_slicing()
pipe.enable_vae_tiling()
```

**不做会怎样**：显存峰值 10.5GB > 8GB → 溢出到共享内存 → **25 秒变 320 秒**。

### 实测对比

| 配置 | 耗时 | 显存峰值 |
|---|---|---|
| 不做优化 | 320 秒 | 10.55 GB ❌ |
| model_cpu_offload | **25 秒** | 5.43 GB ✅ |
| sequential_cpu_offload + CN | 2~4 分钟 | 7.8 GB ✅ |

## 五、ControlNet 姿势控制

### 模型选择

| 模型 | 大小 | 用途 |
|---|---|---|
| `xinsir/controlnet-openpose-sdxl-1.0` | 2.4 GB | **姿势（本方案用这个）** |
| `xinsir/controlnet-union-sdxl-1.0` | 2.4 GB | 一个顶多个（pose/canny/lineart/depth） |
| `xinsir/controlnet-canny-sdxl-1.0` | 2.4 GB | 锁定线稿/服装细节 |

### 骨架来源

**方案 A：从图片自动提取**

```python
from controlnet_aux import OpenposeDetector
det = OpenposeDetector.from_pretrained(r"本地权重目录")
pose = det(image, detect_resolution=768, image_resolution=1120,
           include_hand=True, include_face=False)
```

⚠️ **自动提取的失败率很高**——长裙、遮挡、侧身都会让检测器认不出腿。

**方案 B：自己画骨架（推荐）**

按 COCO 18 点坐标硬编码，直接画线：

```python
POSES = {
    "kneel": {0:(384,168), 1:(384,232), 2:(446,246), ...},
    "sit":   {...},
    "lying": {...},
}
# 用标准 OpenPose 配色画线 + 白点
```

**优点**：完全可控，想什么姿势就什么姿势，不受检测器限制。

### ControlNet 参数

```python
controlnet_conditioning_scale = 0.95   # 太低姿势跑偏，太高画风被压
strength                      = 1.0    # 纯文生图时用
lora_weight                   = 0.66   # 关键！太低颜色漂移，太高姿势跑偏
```

**踩坑**：

- LoRA 0.45 → 头发变亮蓝、眼睛发红（角色跑掉了）
- LoRA 0.72 → 姿势被拉回站姿（LoRA 见过太多站姿）
- **0.66 是平衡点**

## 六、提示词（77 token 陷阱）

**CLIP 只认 77 token，超了直接截断**——后面的「丝袜」「尾巴」全被丢掉，你永远不知道为什么没画出来。

报错提示：

```
Token indices sequence length is longer than the specified maximum sequence length (98 > 77)
```

**对策**：精简到 70 token 以内，**关键项前置**。

```text
clean manga style, cel shading, crisp lineart, matte,
1girl, solo, lanxi, navy blue hair, cyan hair tips, ahoge, whale fin ears,
white lace maid headdress, deep blue eyes,
white victorian maid dress, white apron,
white opaque tights, blue shoes,
single whale tail fin behind skirt, white background, full body, masterpiece
```

### 去油润（关键）

| 位置 | 词 |
|---|---|
| 正向 | `clean manga style, cel shading, flat colors, crisp lineart, matte, dry color` |
| 负向 | `glossy, shiny skin, oily, wet look, bloom, airbrushed, 3d, painterly, plastic, doll-like` |

### 背景控制（不听话时的暴力解法）

```text
正向：simple background, white background, blank background, no background details
负向：room, interior, furniture, window, curtain, floor, wall, cast shadow, gradient background
```

## 七、三种出图模式怎么选

| 模式 | 用法 | 优点 | 缺点 |
|---|---|---|---|
| **txt2img** | 纯文字描述 | 姿势自由 | 角色/服装易走样 |
| **img2img** | 参考图做底 | 画风最稳（90%） | 姿势改不动 |
| **txt2img + ControlNet** | 骨架指定姿势 | **姿势可控 + 画风可调** | 显存吃紧，慢 |

**推荐组合**：

```
日常出图     → img2img 0.45（最像）
要特定姿势   → txt2img + ControlNet（骨架自己画）
批量草稿     → txt2img + LoRA 0.6（快）
```
