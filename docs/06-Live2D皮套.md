# Live2D 皮套制作指南（大肥鱼专用）

> 从零做一套能动的 Live2D 皮套，或者在 1 小时内用替代方案先出片。

---

## 一、先搞清楚：Live2D 到底在做什么

Live2D 不是"建模"，是**把一张静态图拆成很多层，然后让每层按参数动起来**。

```
一张完整立绘
   ↓ 拆分成 40~100 个图层（头发前/后、眼白、瞳孔、高光、嘴、眉、手、裙摆…）
   ↓ 每个图层做成网格（mesh），设置变形用的参数
   ↓ 参数绑定：AngleX（转头）、EyeOpen（眨眼）、MouthOpen（说话）…
   ↓ 导出 .moc3
   ↓ 用 VTube Studio / PrPrLive 加载，摄像头面捕驱动
```

**核心工作量在"拆分"和"绑参数"**，不在画画。

## 二、四条路线对比（按你的情况）

| 路线 | 效果 | 时间 | 难度 | 需要什么 |
|---|---|---|---|---|
| **① PNGTuber+** | ⭐⭐ 只有眨眼/张嘴 | **10 分钟** | 极低 | 3 张图 + 麦克风 |
| **② VRoid 3D** | ⭐⭐⭐⭐ 能转头、能转身 | **2~3 小时** | 中 | VRoid Studio（免费） |
| **③ 真 Live2D** | ⭐⭐⭐⭐⭐ 最像 VTuber | **2~3 天** | 高 | Cubism + 拆分 + 绑定 |
| **④ Inochi2D** | ⭐⭐⭐⭐ 开源替代 | 1~2 天 | 中高 | Inochi2D（免费） |

### 我的建议

```
第一步：PNGTuber+（10 分钟，先出片验证内容）
第二步：VRoid 3D（2 小时，够做所有讲解视频）
第三步（可选）：真 Live2D（有粉丝了再做）
```

**理由**：观众看讲解视频，**90% 注意力在内容和声音上**。先用最低成本跑通，别一上来啃 Live2D。

## 三、路线①：PNGTuber+（10 分钟）

**最适合你现在的阶段。**

### 需要 3~5 张图

| 图 | 内容 |
|---|---|
| `idle.png` | 闭嘴、正常表情 |
| `mouth_open.png` | 张嘴（说话用） |
| `eyes_closed.png` | 闭眼（眨眼用） |
| `mouth_small.png` | 半张嘴（可选） |
| `happy.png` | 笑（可选） |

**全部同一个人物、同一构图、只有表情不同**。

### 出图提示词（本地，25 秒/张）

```text
Q版, chibi, 3头身, 蓝色大肥鱼, 深蓝长发青蓝发梢, 呆毛, 鲸鱼鳍耳,
白色女仆头饰, 蓝白女仆装, 圆润脸型, 笑脸, 张嘴,
简单白色背景, 正面, 上半身, 干净漫画风, cel shading, 白色背景
```

**固定 seed**，只改 `笑脸/张嘴/闭眼/半张嘴`，保证是同一个人。

### 软件

推荐 **PNGTuber+**（免费）或 **Veadotube mini**：

```
导入图片 → 设麦克风 → 张嘴阈值自动切图 → OBS 捕获窗口
```

**配合 OBS 虚拟摄像头 → 剪映里直接用**。

## 四、路线②：VRoid Studio（2~3 小时，推荐）

**这个性价比最高**：能转头、能转身，看起来就是 3D VTuber，而且**不用拆分绑定**。

### 流程

```
① 下载 VRoid Studio（免费，Windows）
② 捏人：脸型、发型（蓝色长发 + 呆毛）、眼睛（深蓝渐变 + 高光）
③ 服装：没有女仆装 → 用基础服装 + 后续贴图，或者去 BOOTH 找免费女仆装
④ 导出 .vrm
⑤ 用 VSeeFace 加载 → 摄像头面捕 → OBS 录制
```

**时间分配**：

| 步骤 | 时间 |
|---|---|
| 捏脸 + 发型 | 60~90 分钟 |
| 服装调整 | 30 分钟 |
| 导出 + VSeeFace 调参 | 20 分钟 |

**缺点**：VRoid 的模板偏"标准二次元"，鲸鱼鳍耳、尾巴要自己做（可以用配件/贴图近似，或者干脆不做）。

## 五、路线③：真 Live2D（2~3 天）

### 软件

| 软件 | 版本 | 说明 |
|---|---|---|
| **Live2D Cubism Editor** | 免费版 | 个人使用够，参数上限有限 |
| Photoshop / Krita | 任意 | 拆分用 |
| VTube Studio | 免费（有水印） | 面捕驱动 |

### 第一步：拆分（最累）

**从一张立绘拆成 40~100 层**。

标准分层清单：

```
头
├── 后发（最底层）
├── 头部底（脸）
│   ├── 眼睛
│   │   ├── 眼白
│   │   ├── 瞳孔（左右分开）
│   │   ├── 高光（左右分开）
│   │   ├── 上睫毛
│   │   ├── 下睫毛
│   │   └── 眼影
│   ├── 眉毛（左右）
│   ├── 鼻子
│   ├── 嘴（闭/半/开/笑，4 套）
│   └── 腮红
├── 前发（刘海，分 3~5 缕）
├── 呆毛（单独一层，要物理）
├── 鳍耳（左右，要物理）
└── 头饰（女仆头饰 + 蓝蝴蝶结）

身体
├── 脖子
├── 躯干（女仆装上身）
├── 围裙
├── 裙摆（分 3~4 层，要物理）
├── 手臂（左右，上臂/前臂/手 分开）
├── 尾巴（要物理）
└── 腿（可省，只露上半身就不用）
```

**自动化可能性**：可以用 SD + 分割模型（SAM/rembg）半自动拆分，但**头发边缘、眼睛高光这种精细层还是得手抠**。

### 第二步：绑定（Cubism）

| 参数 | 作用 |
|---|---|
| `ParamAngleX/Y/Z` | 转头、点头、歪头 |
| `ParamEyeLOpen/ParamEyeROpen` | 眨眼 |
| `ParamMouthOpenY` | 说话 |
| `ParamMouthForm` | 嘴形（笑/撇嘴） |
| `ParamBodyAngleX` | 身体左右倾 |
| `ParamBreath` | 呼吸（自动） |
| `ParamHairFront` 等 | 头发物理 |

**关键技巧**：

- 眼睛要用**弯曲变形器**做"眼球转动"
- 头发用**物理演算**（Cubism 自带），设置摆长/角度
- 嘴用**3~4 个口型层 + 权值切换**，不要只做一个嘴

### 第三步：驱动

```
Cubism 导出 → .moc3 + .model3.json + 纹理
→ VTube Studio 加载 → 摄像头面捕 → OBS 采集
```

**VTube Studio 免费版有水印**，付费约 ¥150。

## 七、B站小号的现实问题

你说要给个 B站小号做视频，但：

| 环节 | 能否自动化 |
|---|---|
| 登录（扫码/验证码） | ❌ 需要你本人 |
| 上传视频 | ❌ 网页控件 + 实名 |
| 封面/简介/标签 | ✅ 我能生成素材 |
| 视频本体（画面+音频+字幕） | ✅ **我能做完** |

**所以分工是**：

```
我：写稿 → 出图 → 合配音 → 剪映工程 → 导出成品 mp4 + 封面 + 简介
你：登录 B站 → 上传 → 点发布
```
