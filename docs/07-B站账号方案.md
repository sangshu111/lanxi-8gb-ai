## 三、内容支柱（4 个系列）

### 系列 1：《8GB 显卡养 AI 老婆》（主线）

**形式**：8~12 分钟，讲解 + 演示

| 集数 | 主题 |
|---|---|
| 01 | 总览：8GB 能做什么（出图 25s / 说话 1.5s） |
| 02 | LoRA 训练：20 张图怎么训出角色 |
| 03 | 语音：零样本 vs 微调，差在哪 |
| 04 | ControlNet：任意姿势怎么锁 |
| 05 | 全流程整合：从 QQ 消息到语音回复 |

### 系列 2：《踩坑实录》（短，3~5 分钟）

**每个视频只讲一个坑**，标题要具体：

- `为什么 AI 画不出丝袜？我查了 3 天，原因是 77 个 token`
- `出图 320 秒 vs 25 秒：只差三行代码`
- `AI 配音为什么沙哑？因为我少给了一段文字`

**这类视频最容易爆**——搜索流量大。

### 系列 3：《模型对比》

- GPT-SoVITS vs CosyVoice2 vs IndexTTS2（同段台词）
- Illustrious vs NoobAI vs Pony（同提示词）

**观众爱看对比**，而且能长期被搜索到。

### 系列 4：《直播切片》（后期）

等形象做好，用 Live2D/VRoid 做直播，切片发上来。

## 五、自动化：投稿能不能自动

### 结论：**能，但要一次性扫码授权**

B站没有对个人开放的正式上传 API，但社区有成熟方案：

| 工具 | 能力 | 说明 |
|---|---|---|
| **biliup-rs** | 扫码登录 + 视频上传 + 稿件信息 | Rust 写的 CLI，最稳 |
| bilibili-API-collect | 接口文档 | 参考用 |

**流程**：

```
① 你扫一次码（biliup 登录，cookie 存本地）
② 我写好 metadata（标题/简介/标签/分区/封面）
③ 我调 biliup 上传 → 返回稿件 ID
④ 你在创作中心点"发布"（审核前最后一步）
```

**注意**：

- cookie 有效期约几个月，过期要重扫
- **不要高频上传**（一天最多 1~2 条），否则触发风控
- 三个"人"共用账号 = **同一个 cookie**，别同时登

## 七、涨粉的现实预期

| 阶段 | 目标 | 关键动作 |
|---|---|---|
| 0~100 粉 | 找到对的选题 | 前 5 条试 5 个方向 |
| 100~1000 | 稳定输出 | 每周 1 条，固定栏目 |
| 1000 粉 | 开通激励 | 持续 + 互动 |
| 1 万粉 | 接单/合作 | 建立作品集 |

**现实**：技术区涨粉慢，但**粉丝精准、变现强**。

**别指望爆款**——第一条能有 500 播放就算成功。
